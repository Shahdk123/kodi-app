# كودي — Egyptian Arabic Python Tutor (Mobile App)

## Architecture
- **React Native + Expo** — mobile app (iOS & Android)
- **All lesson logic on-device** — no server needed for lessons or TTS
- **Native TTS** — expo-speech → Siri voices on iOS (instant, great Arabic)
- **Python backend (server.py)** — only needed for the code editor's Run button

## Setup

### 1. Install Node + Expo CLI
```bash
brew install node                  # macOS
npm install -g expo-cli
```

### 2. Install app dependencies
```bash
cd KodiApp
npm install
```

### 3. Start the Expo app
```bash
npx expo start
```
Then press `i` for iOS simulator, `a` for Android, or scan QR with Expo Go app.

### 4. (Optional) Start the Python code runner
Only needed if you want the ▶ Run button in the code editor to work.
```bash
pip install flask flask-cors
python server.py
```

## Adding more lessons
1. Create `src/data/lesson02.js` with a `STAGES` array
2. Import it in `lessonEngine.js` and add to a `LESSONS` dict
3. Add navigation between lessons in TutorScreen

## Using a real phone (not simulator)
In `src/utils/codeRunner.js`, change `localhost` to your Mac's local IP:
```js
const BASE_URL = 'http://192.168.1.X:5001';   // your IP from System Preferences → Wi-Fi
```

## Web version on GitHub Pages
- Python runs **in the browser** (Pyodide in a Web Worker) — no `server.py` needed on web (`src/utils/codeRunner.web.js`).
- Voice input uses the browser Web Speech API, `ar-EG` (`src/hooks/useSpeechRecognition.web.js`) — works in Chrome/Edge/Safari.
- `app.json` → `experiments.baseUrl` must equal your **repo name** (currently `/kodi-app`).
- Local test: `npm run build:web` then serve `dist/` under that sub-path.
- Deploy: push to `main`; in the repo go to Settings → Pages → Source: **GitHub Actions**.
- Native (iOS/Android) still uses `codeRunner.js` + `server.py`.

## Puzzle lesson (default screen)
- `app/tutor.jsx` → `src/screens/NubiaLessonScreen.jsx` (Arabic only, tap-to-order puzzles, Nubian village on the Nile, drifting birds / boats / camel).
- Lesson content: `src/data/nubiaLesson01.js` — add stages of type `teach | demo | order | choice | wrap`.
- Puzzle output comes from `src/utils/printSim.js` (instant, no server). The older chat screen (`TutorScreen.jsx`, mic + typing) is kept but unused.
- Background illustration: `assets/nubia.jpg` (generated by `scripts/make_bg.py`; edit and re-run to change it).
- Metaphor: print = painting on the wall 🎨 · ( ) = the door 🚪 · " " = the Nubian house 🏠 · numbers = free travellers 🐪.
